## 10. Figma issues

- `theme/opacity/white/20` aliases `product/white/opacity/25` (25% white, not 20%). `product/white/opacity/20` exists but is unused.
- `space/container/sm/gap outside` aliases a variable from another library file (`VariableID:4cbba4ee0431dc99a284bee454f2903bf28de8c7/15657:223` — the published library's own `space/unit/75`, 6px). Re-pointed to the local `space/unit/75` in the tokens; fix the alias in Figma.
- `theme/accent` has cyan, magenta, olive, orange, pink, taupe but no periwinkle; 4 semantic color tokens reference `product/periwinkle/*` primitives directly (`color/background/static/accent periwinkle`, `color/background/static/accent periwinkle subtle`, `color/icon/accent periwinkle`, `color/text/accent periwinkle`). certara-ui has `--theme-accent-periwinkle-*`; they are kept as extended tokens.
- Semantic tokens that skip the theme layer and alias primitives directly: `color/background/static/accent cyan subtle`, `color/background/interactive/nav item/hovered`, `color/text/accent cyan`, `color/text/accent magenta`, `color/text/accent olive`, `color/text/accent orange`.
- 447 variables use `ALL_SCOPES` (every property picker) — mostly Color Primitives (221) and all 174 `theme/*` colors. Scope them (e.g. primitives to none, since the collection is hidden).
- `color/background/interactive/disabled` is the only variable with codeSyntax (WEB = `bg-disabled`), which doesn't match its generated CSS name `--color-background-interactive-disabled`. Set codeSyntax.WEB on all variables to the generated names (or none).
- Font weights are Figma font-style strings (e.g. `inter-weights/400 Regular` = "Regular"), not numbers; @certara/styles maps them to 100–900. Italic variants map to the same numeric weight (italic is a font-style).
- `font/family/*` holds only the family name ("Inter"); fallback stacks are added in @certara/styles.
- Text style `Headings/h5/Semibold (600)` exists 3 times with different line heights (150%, 130%, 110%).
- Text style `Body/xs/Medium (500)` is named 500 but uses weight 400 (Regular).
- Text style `Headings/h5/Semibold (600)` uses font style "SemiBold" (Inter's style is "Semi Bold"), so it isn't bound to a real font style.
- Text style `Headings/h6/Semibold 150 (600)` is named 600 but uses weight 500 (Medium).
- Nav Bar Modes (`Is expanded`, `Is collapsed`, `Global nav bar width`, `Designer nav bar width`) are prototype state; not emitted as CSS. certara-ui's `--sidebar-nav-global-width` (64px) equals the Collapsed "Global nav bar width" but Expanded is 200px vs code's contextual width of 208px.

## 11. Bugs in certara-ui found along the way

- Referenced but never defined in light: `--space-unit-400`, `--theme-opacity-black-15`, `--theme-opacity-black-50`, `--theme-opacity-white-15`, `--theme-opacity-white-transparent`, `--theme-white-opacity-25`.
- Referenced but never defined in dark: `--theme-cyan-300`, `--theme-magenta-300`, `--theme-periwinkle-300`, `--theme-white-opacity-15`.
- `.bg-gradient` uses `var(--gradient)` and `.rounded-pill` uses `var(--border-radius-pill)`; neither is declared on `:root` (`--gradient` is only set inside button styles), so both utilities do nothing on their own. `--border-radius-pill` was probably meant to be `--border-radius-full` (Figma `border/radius/full`).
- `sass-utils/_utilities.scss:118-150` — `var(--border-width, --border-width-default)`: the fallback is a bare custom-property name, which is invalid (harmless only because `--border-width` is always defined).
- `sass-utils/_utilities.scss:465` — the `py` utility sets `padding-block-start` and `padding-block` instead of `padding-block-start` + `padding-block-end`.
- `sass-utils/_variables-base.scss:145` — `ar(--color-link-brand-inverse-hover)` is missing the `v` of `var(`.
- `--table-striped-bg: rgba(var(--theme-neutral-400), 0.05)` — `--theme-neutral-400` is a hex color, so this rgba() is invalid. Emitted verbatim; should use `--theme-neutral-400-rgb`.
- `[data-theme=dark]` declares the tab and table background variables twice (lines from the "figma sync" block and again with hex fallbacks); the later declarations win.
- Semantic aliases such as `--body-color: var(--color-text-primary)` are declared only on `:root`, so a nested `[data-theme=dark]` element inherits the light value. @certara/styles re-declares every mode-dependent variable inside `[data-theme=dark]`.
- 9 certara-ui variables resolve to an undefined variable in at least one mode (see the undefined names above): `--color-text-accent-cyan`, `--color-text-accent-magenta`, `--color-text-accent-periwinkle`, `--color-background-static-overlay`, `--color-background-interactive-nav-item-default`, `--color-background-interactive-nav-item-hovered`, `--color-background-interactive-nav-item-selected`, `--color-border-interactive-button-default`, `--space-grid-gap`.

## 12. Not syncable through Token Nexus

- **Effect styles** (16) → `extended/shadow.json`, generated from Figma by `import-figma.mjs`. Figma has no dark-mode shadows; `--shadow-100` and `--btn-box-shadow` keep certara-ui's dark values.
- **Text styles** (45 non-icon) → only heading line heights are captured (`extended/typography.json`). Heading weights can't be derived: each heading has several weight styles.
- **Everything in `extended/`** — not Figma variables.
- **Collections not emitted as CSS:** `color-primitives` (hidden from publishing in Figma; references to it resolve to hex); `nav-bar-modes` (component state (booleans) and prototype widths, not styling tokens).

## 13. Utility classes

- @certara/styles compiles the same Sass utility generator as certara-ui. Its selector set is verified identical to the `certara.utilities` layer of `global.css` (`npm run verify -w @certara/styles`).
- References to renamed variables were rewritten to the new names. The color utilities whose class names come from Sass map keys (`.text-gray-100`, `.bg-dark`, `.text-accent-orange`, …) still read deprecated `-rgb` aliases (`--theme-gray-100-rgb`, …); renaming those means renaming the classes.
- The utility partials still use Sass `@import` (deprecated, removed in Dart Sass 3).
